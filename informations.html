Mentions légales

MON UNIVERS TECH présente des applications et un comparateur d’offres. Les achats éventuels se font sur les sites des marchands.

Les coordonnées de l’éditeur, du responsable de la publication et de l’hébergeur seront renseignées avant l’ouverture commerciale.

Pour signaler un problème technique, consultez le dépôt GitHub du projet.

Confidentialité

La sélection de catégories est conservée dans le stockage local du navigateur. Vous pouvez l’effacer avec « Vider la sélection ». L’installation de l’application enregistre des fichiers du site pour un accès hors ligne.

La conversation locale reste dans la mémoire de la page. Si l’option IA externe est disponible et activée, le message saisi et un extrait du catalogue sont envoyés à OpenAI pour obtenir une suggestion technique. Évitez de saisir des données personnelles. Le serveur demande une réponse sans stockage via le paramètre store=false. Le compteur serveur conserve uniquement les dates des appels. Les conditions de traitement et les modalités d’exercice de vos droits seront complétées avant l’ouverture au public.

Le navigateur consulte le flux public de PRIX MALIN pour obtenir les offres. Les liens externes ouvrent des sites qui appliquent leurs propres règles de confidentialité.

Affiliation

Les liens signalés « lien affilié » peuvent verser une commission à MON UNIVERS TECH lorsque vous effectuez un achat. Le classement utilise le prix total, livraison incluse lorsqu’elle est connue. Vérifiez les prix et disponibilités sur le site du marchand.
